# BARBER ONE

Демонстрационный сайт барбершопа, созданный для портфолио.

🔗 [Открыть сайт](https://heavy35.github.io/barber-one/)

## Что реализовано

- Адаптивная версия для компьютера и телефона
- Анимации при прокрутке
- Разделы об услугах и пространстве
- Демонстрационная форма онлайн-записи

## Технологии

HTML, CSS, JavaScript.

## О проекте

BARBER ONE — дизайн-концепт. Цены приведены для примера. Запись работает как демонстрация интерфейса: заявка не отправляется в настоящий барбершоп.
